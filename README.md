### 👋 About Me

I'm a Flutter developer focused on building production-grade mobile apps end to end — architecture, backend integration, and polish. My current work centers on **EdTech for Pakistani students**, combining app engineering with structured, syllabus-aligned content.

- 🚀 **Currently building:** *Genius* — a Flutter academy app delivering ETEA & MDCAT entry-test prep, with a large MCQ question bank across Physics, Chemistry, Math, and English, backed by Firebase Auth and Firestore
- 🏗️ **Focus areas:** Clean architecture, role-based routing, offline-first caching (SharedPreferences), and reliable state management with Firestore sync
- 🌱 **Also exploring:** AI-assisted interfaces in Flutter
- 🎯 **Goal:** Ship polished, reliable mobile products that solve real problems for real users
